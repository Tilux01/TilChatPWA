# TilChat

A full chat application built as a progressive web app with offline support.

## About

TilChat is my biggest personal project. It is a complete chat platform with real time messaging, media sharing, music playback and an AI assistant, all running as an installable PWA with Firebase sync.

## Features

- Real time messaging
- Media sharing and file uploads
- YouTube music playback built in
- AI chat assistant
- Offline support with service workers
- Firebase authentication and sync

## Tech Stack

- React
- PWA
- Firebase
- Service Workers
- CSS

## Getting Started

Clone the repository and open the project in your browser or run it with your preferred local server.
